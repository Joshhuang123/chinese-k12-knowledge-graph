# 可选组件：向量检索层（Milvus）

> **这个目录是可选的 —— 主项目一行都不依赖它。**
>
> 主项目是**静态站点 + jsonl 数据层**：双击 `index.html` 就能玩，
> agent 直接读 `data/learn-cards.jsonl` 就能用，**零第三方依赖**。

## 这个组件解决什么

**让你能用自己话说出那个概念。**

上游概念名大量是改写过的——
「ATP（能量储存形式）」「DNA（遗传信息载体）」「数方格估计面积」——
教材里根本不这么写。**精确字面匹配只覆盖 4.6%。**

这一层把 2.3 万页教材切成 5.5 万个段落、建向量索引，
就能用「为什么苹果会掉下来」这种话找到相关段落。

## 什么情况下值得装

| 你的情况 | 值不值 |
|---|---|
| 「我要按概念名查教材原话」 | **不用装** —— `data/learn-cards.jsonl` 的 `read` 面直接给（32% 覆盖） |
| 「我要按书/页码筛」 | **不用装** —— 学习卡的 `where` 面给的是哪本书哪一页 |
| 「我要知道这个概念前面该学什么」 | **不用装** —— 学习卡的 `prereq` 面 |
| **「我要用自己的话问教材」** | **得装** —— 这是这一层唯一的独有价值 |
| 「我要批量做语义检索实验」 | 得装 |

**一句话：只有「用自己的话问」这一件事需要它。**

## 用法

```bash
# 起库
pip install -r requirements.txt
ollama pull bge-m3
python3 build_milvus.py

# 查
python3 query_milvus.py "浮力"                          # 语义检索教材原文
python3 query_milvus.py "浮力" --edition 人教版 --book 8b
python3 query_milvus.py --prereq 浮力                    # 查前置关系

# 校验
python3 check_milvus.py             # 8 组判据（含正负例 golden set）
python3 check_milvus_judgement.py   # 判别力自检（注入脏数据 → 必须报红）
```

| 版本 | 要求 | 库的样子 |
|---|---|---|
| **3.x**（推荐，当前版） | Python ≥ 3.10 + `pymilvus>=3.0` | `.db` 是个**目录** |
| 2.5.x（老版） | Python 3.9 + `pymilvus==2.5.1` | `.db` 是**单个文件** |

**两代的库不能互相读** —— 换版本 = 重建（45 分钟）。

## 两条要注意的

### 1. 向量检索给的是「相关段落」，不是「这就是定义」

查「浮力」，它给你教材里讲浮力的那几段 ——
**哪一段是「定义」，哪一段是「例题」，得你自己看**。

想要**已经被判过是定义句**的那些，用 `data/learn-cards.jsonl`，
每段带 `kind` 标记：
- `教材定义句` —— 教材在给这个概念下定义（证据最强）
- `教材提及句` —— 教材提到了它，但不是定义句
- `图谱定义` —— **数据集的转述，不是教材原话**

⚠️ **`图谱定义` 不能当教材原话引用。**

### 2. 教材版权页没有入库

教材前十几页是版权页 / 编者信息（「版权所有…未经许可不得另做他用」）。
这些**没有进库** —— 检索时不该召回版权声明，
数据库里也不该复制教材的版权信息。

入库的是**从教材里抽出来的段落**，性质跟 `data/lessons.jsonl` 一样。
教材 PDF 本身不随本仓库分发。

## 为什么是 Milvus（而不是直接上向量库）

先按 Milvus 官方 workshop 那份 `15-retrieval-tier-selection.md`
的检索复杂度阶梯评估过 —— 那份 spec 自己写着
「从阶梯顶端起步是**教学选择，不是工程默认**」，
而且它实测的结论是 **T0→T1（词法 + 查询改写）带来全部质量增量，T2（向量）相对 T1 是 0**。

我们自己的实测（12 个「BM25 找不到定义句」的真实概念）：

| 方案 | 结果 |
|---|---|
| 纯 BM25 | 5/5 命中 |
| 纯语义（`nomic-embed-text`，本机 274 MB） | **0/15** —— 英文模型，「邻补角」召回「近似数」 |
| 纯语义（`qwen3-embedding:8b`，本机 4.7 GB） | 4/4 正确项排第一，但 10 秒/条 → 全量 37 小时 |
| 纯语义（**`bge-m3`**，本机 1.2 GB） | 5/5 正确项在 top-2，**0.05 秒/条** → 全量 45 分钟 |

**选 `bge-m3`**：中文质量够、速度够、本机跑得动、**教材不出境**
（教材有版权，嵌入全在本机算完，只把向量存本地）。
