# 讲解稿写作协议

一个概念一条讲解稿。稿子是**唯一的手写输入**，视频和页面上的文字讲解都由它生成。

素材包在 `data/lesson-drafts/<概念id>.json`，输出写到 `data/lesson-scripts/<概念id>.json`。

---

## 一、为什么稿子是唯一手写输入

视频是稿子的配音版，页面上的「讲解」卡片是稿子的文字版。
**稿子写一次，两处一致** —— 不会出现「视频讲一套、页面写另一套」。

---

## 二、输出格式

```json
{
  "id": "math_9b_rjb_cpt1",
  "version": "rjb",
  "name": "反比例函数",
  "kicker": "人教版 · 九年级下册 · 第二十六章 反比例函数",

  "hook": "反比例函数也叫双曲线——但它在纸上根本画不完。",

  "definition": "形如 y = k/x（k≠0）的函数。x 每变大一点，y 就小一点，但一直减不下去。",

  "quote": {
    "text": "……（教材原话，一字不改）",
    "src": "人教版《数学》九年级下册 印刷页 12（教材原话）"
  },

  "formulas": ["y = k/x", "k = xy"],

  "page": {
    "image": "data/pages/math-9b/12.webp",
    "where": "人教版九年级下册 第二十六章 · 印刷页 12",
    "lines": ["这一页是……", "……"]
  },

  "chain": [
    { "name": "反比例函数", "tag": "现在学的" },
    { "name": "一次函数", "tag": "先会它" },
    { "name": "函数", "tag": "再往前" }
  ],
  "chain_title": "学它之前要先会",
  "chain_label": "这几样要先会",

  "endText": "教材原页 · 教材原话 · 例题 · 完整前置链，都在学习页里。",

  "scenes": [
    { "id": "s0_cover",   "title": "封面",     "text": "……" },
    { "id": "s1_what",    "title": "它是什么", "text": "……" },
    { "id": "s2_page",    "title": "教材原页", "text": "……" },
    { "id": "s3_chain",   "title": "卡在哪",   "text": "……" },
    { "id": "s4_end",     "title": "结尾",     "text": "……" }
  ],

  "explain": {
    "lines": ["……（五段，与 scenes 的 text 一致）"],
    "from": "讲解稿 · 与视频同源（视频是这份稿子的配音版）"
  }
}
```

**字段来自素材包的，照抄**：id / version / name / formulas / page.image / page.where / chain。
**要你自己写的**：kicker / hook / definition / quote / page.lines / chain_title / chain_label /
endText / scenes / explain.lines。

---

## 三、硬约束

1. **不许编造。** 定义、公式、教材原话**只能来自素材包**。
   素材包里的 `quotes` 是教材 OCR 出来的原文，可能是残骸
   （形如「二次函数7一a(x十丸)十六」）；**残骸就别引用**，换一条干净的，
   都没有就**不写 quote 这个字段**（页面会少一块，比引用错话好）。

2. **`quote.text` 一字不改。** 它是教材原话。`quote.src` 写清楚出处和**印刷页码**
   （用素材包的 `page.printed`，**不是**扫描页）。

3. **钩子 15 字左右，第一句就抓住人。** 四型轮着用：
   - **反常识**：「钢铁做的轮船能浮，钢铁做的螺母却沉。」
   - **数据冲击**：「一个数能倒着写出来，这事听起来像算命。」
   - **后果**：「这一个符号认错，整道题的答案就反了。」
   - **类比悬念**：「反比例函数长这样：怎么画都画不完的那条线。」
   **同一个批次里不许连着两条用同一型。**

4. **数字一律汉字**（「第 49 页」写「第四十九页」），专有名词保留英文/字母（y、k、x、F浮）。
   公式里的字母和数字**保留原样**（公式不是口播稿）。

5. **总口播 230–300 字**（对应 50–65 秒）。**别超 90 秒**（平台红线）。

6. **`scenes` 恰好 5 个**，`id` 依次是 s0_cover / s1_what / s2_page / s3_chain / s4_end。

7. **`explain.lines` 与 `scenes[].text` 内容一致**（顺序也一样）——
   页面上的文字讲解和视频必须说同一件事。

8. **`page.image` 用素材包给的原样**（相对路径 `data/pages/...`）。

## 四、每场写什么

| 场 | 标题 | 写什么 | 时长 |
|---|---|---|---|
| 0 | 封面 | **钩子**。第一句就要让人停下来。 | ~20 字 |
| 1 | 它是什么 | 一句话说清它是什么 + 教材自己的话。**别念定义**——定义在画面上。 | ~60 字 |
| 2 | 教材原页 | 指一页书：「翻到人教版九年级下册第二十六章，第 12 页」。**主视觉是那张真教材页图。** | ~50 字 |
| 3 | 卡在哪 | 学它之前要先会哪几样。**只说真前置**（素材包里的 prereq 是真的）。 | ~50 字 |
| 4 | 结尾 | 往下是什么 + 去学习页。 | ~45 字 |

**第 3 场的 chain**：
- 素材包 `prereq` 非空 → `chain` = [自己] + prereq（前 3 个），`chain_title` = 「学它之前要先会」
- 素材包 `prereq` 为空 → `chain` = [自己] + successor（前 3 个），`chain_title` = 「接下来会学」，
  `chain_label` = 「顺着往下学」

---

## 五、什么算好

不是「格式对」，是**学生看了真懂**。自查三条：

1. **封面那句话，能不能让人想问「然后呢」？** 不行就重写。
2. **第 1 场的话，跟画面上的定义是不是同一件事？** 重复就是废话。
3. **第 2 场说的话，跟那张教材页图对得上吗？** 对不上就是编的。

一句话标准：**这份稿子念出来，一个初二学生看完知道这个概念是什么、在书第几页、
学之前要先会什么、以及接下来去哪。**
