# 中文知识图谱

**中国孩子在学什么？按人教版教材的顺序，一根锥形。**

把 K1 到 K12 的知识点摊开：横向一个知识点就是一个可以单独教、单独考的小概念，纵向是年级。每个点之间的连线是「先修」——学上面这个之前，得先会下面那个。

单文件、零依赖、不联网。双击 `viz/知识图谱3D.html` 就开。

---

## 这个项目是什么，不是什么

**不是**「再做一个知识图谱」。北大那套 K12-KGraph 做得比我们好，我们不重做，也不重标数据库。

**是**在它上面补一层两件事：把异构的原始数据归一化，然后**校验**。

因为上游自己漏了两个环：

- 「极性分子」说学「相似相溶规律」前要先会它，反过来也这么说 —— 逻辑上不可能同时成立
- 「化学键能量变化与反应热」和「根据键能估算反应热」互为前置

这两组边都在官方 `global_KG/edges.json` 里，不是我们归一化造出来的。K12-KGraph 的论文里写了 `DAG validation`，但这两个环漏过去了。

**校验本身也需要被校验** —— 这是这个项目真正的立足点。详见 [`known-issues.md`](known-issues.md)，包括我们自己的校验层出过的 bug。

### 教材版本这件事，公开信息里是空的

论文、README、数据集卡片、源文件仓库路径——**四个地方都没有标注审定年份或版次**。

能确认的只有：

| | 结论 |
|---|---|
| 出版社 | 人民教育出版社（人教版），小学数学 / 初中数学 / 物理 / 化学 / 生物 |
| 高中数学 | 人教 **A 版**（章建跃、李增沪主编） |
| 高中部分版本 | **可以钉死在 2019 年统编教材之后**——册次命名是「必修第一册 / 选择性必修一~三」，这套命名法只有 2017 课标修订后的统编高中教材才有 |
| 小学 / 初中版本 | **存疑**。源文件仓库里 `义务教育教科书 · 数学五年级上册.pdf` 最后提交是 2024-06-23，而义务教育数学新教材 2024 年秋天才铺开。**推断**（未核实）：很可能是 2024 年之前的老版 |

**教材 PDF 不是从人教社官网拿的**，论文 §7.2 脚注 1 指向社区整理仓库 [`TapXWorld/ChinaTextbook`](https://github.com/TapXWorld/ChinaTextbook)。论文称其为 "official textbook PDFs"，指的是「真的人教版教材」，来源渠道是第三方。

那个仓库每个年级只有一册，没有新旧并存，所以是单一快照。**如果你手上有具体某册书，目录页对一遍 `math_5a` 的知识点顺序，就能确认是不是同一版。**

## 致谢

这个项目站在两件事上面，一件是数据，一件是启发。两件都要说清楚**具体是什么关系**，不然就是含糊其辞。

### 数据：K12-KGraph（北京大学 PKU-DCAI）

**本项目的全部原始数据都来自这里**，一个字节未改。本项目没有自建任何教材抽取流程——北大那套做得比我们好，我们不重做，也不重标数据库。

上面那一段署名与许可（CC BY-NC-SA 4.0）**不是客套，是这份许可的硬性要求**。转手时必须一并带上。

### 启发：Marble Skill Taxonomy（美国）

**不是数据来源，也不是代码来源。** 这两件事要分开说，因为很容易被说混：

- **数据没用到。** 本仓库里没有任何 Marble 的数据。 Marble 的 `topics.json` / `dependencies.json` 归 ODbL 1.0，其撰写的文本内容归 CC BY-SA 4.0 —— 这两份许可**都没有出现在本仓库里**。
- **代码没抄。** `viz/template.html` 这套手写 canvas 3D 渲染器是本项目自己写的。已逐字节核对：Marble 官方仓库全树 24 个文件，**不包含任何 `.html` 源码**——他们的交互式可视化（withmarble.com/curriculum）根本不公开。我们是看了那个公开网站之后自己实现的。

那么为什么还要专门致谢？

**因为是它让这个项目的缺口显形。**

2026 年 7 月，Marble 发布了一套美国 K-12 知识图谱：1,590 节点 / 3,221 边，交互式 3D 可视化做得很好看。同一时间，我们想找一套国内的中文教材知识图谱，找遍 GitHub 只有零散几个学生项目。

**一个像样的公开可视化都不存在**——这件事本身，比「缺一个可视化」严重得多。它说明的不是没人做，是做出来也没人看，看了也没人指出问题。

Marble 那套确实把可视化做得很好。但它 2026-07-08 发布之后再没推过任何一次 commit，5,478 star、924 fork，底下挂着 **18 条 open issue**——其中 #11 质疑 14 个主题名和内容对不上（实测 4 例确实对不上），#18 质疑依赖关系荒谬，唯一回复是有人说想认领去修。三个月了，没人动。

**所以本项目真正要证明的是：校验本身也需要被校验。** 一套图谱如果没人查，成环了没人知道，主题名和内容对不上也没人知道。

对照着做的过程中发现的东西，都记在 [`known-issues.md`](known-issues.md) 里——包括上游自己漏掉的两个环，以及我们自己的校验层出过的 bug。

**致谢 Marble，是因为它把问题摆在了明面上。**

### 教材原文：人教社 PDF，经社区仓库取得

K12-KGraph 的教材 PDF 由论文作者从 [`TapXWorld/ChinaTextbook`](https://github.com/TapXWorld/ChinaTextbook) 下载。本项目与该仓库无直接关系，列在这里是为了让出处链完整可追。

## 怎么跑

需要 Python 3，零第三方依赖。

```bash
python3 src/normalize.py     # 原件 → data/normalized/graph.json
python3 src/validate.py      # → data/normalized/validation.json，有硬错误时 exit 1
python3 src/build_viz.py     # → viz/知识图谱3D.html
```

只想到成品页，直接 `open viz/知识图谱3D.html` 就行。

**注意 `validate.py` 现在会 exit 1**，这是对的——两个环还没修（要修得去改上游）。

## 三层结构

```
data/raw/              原件，只读，一个字节没动（15 MB）
  global_KG/           跨册合并后的骨架：10,685 节点 / 23,278 边
  subject_specific_KG/ 单科细节，教材原文引用只在这里
src/normalize.py       归一化层：4 种边 schema 合一，一对多边展开
src/validate.py        校验层：成环 / 悬空 / id 重复 / 空名 / 自环
src/build_viz.py       可视化层：压成紧凑数组 + 换成中文口径
viz/知识图谱3D.html    成品（1.9 MB）
known-issues.md        已知问题清单
```

### 画出来的部分

7,938 个节点（概念 + 技能，习题/实验/节/章/册是容器或素材，不画），3,408 条先修边。

**看一眼就该注意到的事**：锥形底部整片纯蓝，只有数学。

小学阶段（1a–6b）**只有数学**，782 个知识点；物理、化学、生物的小学内容，一个都没有。

往上走，物理/化学/生物才逐渐加入，到初中是 4 科 2,655 个。

## 交互

| 操作 | 效果 |
|---|---|
| 拖拽 / 滚轮缩放 | 转视角 |
| 点一个点 | 看它的定义、课程要求等级、前置链 |
| 左下角学科开关 | 单看某一科 |
| `只看初中` | 只留中考段 |
| `显示连线` | 关掉省一点性能 |
| `自动旋转` | 挂机看 |
| `复位` | 回默认视角 |

「课程要求」是课标的三级：**掌握 / 重要 / 了解**。7,938 个知识点里分别是 3,065 / 2,112 / 1,393，另外 1,367 个上游没标要求等级（显示 `—`），还有 **1 个写的是「理解」，不在三级之内**——大概率是抽取时的用词漂移。

## 边界

- **只覆盖人教版。** 沪教版、苏教版没做——但源仓库里高中化学同时有沪科技版、苏教版、鲁科版，**扩版本在数据源上是可行的**，不是没得做。
- **只覆盖理化生数。** 语文、英语、道德与法治、历史、地理不在上游数据里。
- **只覆盖中国。** 跟 Marble 那套美英图谱（1,590 节点）不是一套东西，册次和学段对不上，不能直接叠在一起比。
- **数据是 2026 年 5 月的教材快照。** 教材改版不会自动跟上，且上游没标注是哪一版（见上）。
